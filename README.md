# LJRDev Portfolio

Welcome to the public repo for [LJRDev.com](https://ljrdev.com) — a professional portfolio built by me, Lucas Ralph, showcasing software engineering projects, frontend animation skills, and Contentful-powered dynamic content.

---

## 🧱 Tech Stack

| Layer          | Tech Used                                                     |
| -------------- | ------------------------------------------------------------- |
| **Frontend**   | [Next.js](https://nextjs.org), TypeScript                     |
| **Styling**    | SCSS Modules, GSAP (GreenSock), Swiper.js                     |
| **CMS**        | [Contentful](https://contentful.com)                          |
| **Forms**      | React Hook Form, [Resend](https://resend.com) (email service) |
| **Images**     | Contentful and `next/image` for optimization                  |
| **Hosting**    | Vercel                                                        |
| **Validation** | [Zod](https://zod.dev) for runtime schema validation          |
| **Analytics**  | Vercel Analytics, Vercel Speed Insights                       |
